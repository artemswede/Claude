# Описание продукта (ChatGPT) — результат

> Источник: прогон промпта `ПРОМПТ-CHATGPT-описание-продукта.md` в ChatGPT. Используется как вход для бизнес-требований (Шаг 1).

## 1. Elevator pitch
ИИ-нутрициолог в Telegram, который превращает фото еды в учёт питания без ручного ввода: распознаёт блюдо, считает КБЖУ, ведёт дневник и подсказывает, что съесть дальше для достижения цели. В конце дня формирует готовую корзину продуктов и переводит пользователя к заказу по ссылке.

## 2. Проблема пользователя
- **Боль 1.** Учёт питания требует слишком много времени (поиск продукта, взвешивание, ручной ввод).
- **Боль 2.** Нет понимания прогресса по целям (сколько КБЖУ набрано, что можно съесть).
- **Боль 3.** Не хватает персональных подсказок по коррекции следующего приёма пищи.
- **Боль 4.** Разрыв между планированием и покупкой — не хочется отдельно составлять список.
- **Боль 5.** Быстро падает мотивация — ручное ведение превращается в рутину и забрасывается.

## 3. Решение и ключевая ценность
Telegram-бот: фото → распознавание блюда → расчёт КБЖУ → запись в дневник → прогресс по целям → рекомендация на следующий приём → корзина продуктов со ссылкой на заказ.
**Ключевая ценность:** от фото до покупки полезных продуктов в одном интерфейсе Telegram без ручного ввода.
**«Вау»-момент:** одно фото обеда → оценка КБЖУ + обновлённый дневник + остаток по целям + совет на ужин + готовый список продуктов.

## 4. Персоны
- **Офисный специалист, 29, Москва, 150 000 ₽.** Цели: снизить вес, перейти на ПП, не тратить время. Барьеры: нет времени, быстро бросает трекинг. День: завтрак дома → офис → доставка на обед → спортзал → заказ продуктов онлайн.
- **Молодой руководитель, 34, СПб, 220 000 ₽.** Цели: контролировать рацион, держать форму, автоматизировать рутину. Барьеры: часто ест вне дома, не знает калорийность. День: кофе → встречи → ресторан на обед → поздний ужин → заказ продуктов.

## 5. User stories
1. Отправить фото еды → быстро получить оценку КБЖУ.
2. Видеть распознанное блюдо → убедиться в корректности.
3. Автоматически сохранять приёмы пищи в дневник → не вводить вручную.
4. Установить дневные цели по КБЖУ → контролировать питание.
5. Видеть остаток по калориям и макросам → планировать следующий приём.
6. Получать рекомендации на обед/ужин → легче держать цель.
7. Видеть список рекомендуемых продуктов → подготовиться к следующему дню.
8. Перейти по ссылке на заказ корзины → не искать продукты самому.
9. Просматривать историю питания за день → оценивать прогресс.
10. Доверять расчётам → использовать регулярно.

## 6. Функциональные требования MVP
1. Авторизация через Telegram (старт бота, профиль).
2. Настройка целей (дневная цель по КБЖУ).
3. Загрузка фото блюда в чат.
4. Распознавание блюда + показ результата.
5. Расчёт КБЖУ + отображение.
6. Дневник питания (автосохранение, итоги за день).
7. Прогресс по целям (потреблено/осталось).
8. Текстовые рекомендации на следующий приём.
9. Корзина продуктов (список рекомендуемых).
10. Переход к заказу (кнопка с внешней ссылкой/диплинком).
11. Сбор аналитики (логирование ключевых действий для KPI).

## 7. Out of scope (не в MVP)
Реальное оформление заказа, интеграции с дарксторами, оплата, мед. рекомендации, интерпретация анализов, консультации врачей, микронутриенты, план на неделю, интеграция с фитнес-трекерами, соцфункции, подписка/платные функции, персональные программы питания.

## 8. Happy path
**Первый запуск:** старт бота → задать дневную цель → инструкция «отправьте фото еды».
**Использование:** фото завтрака → распознавание → КБЖУ → автосохранение → фото обеда → обновление дневника → прогресс по цели → рекомендация на ужин → формирование корзины → «Заказать корзину» → переход по ссылке/диплинку.

## 9. Отличие от обычного трекера КБЖУ
1. Фото вместо ручного ввода — основной способ.
2. Telegram как единая точка входа, без отдельного приложения.
3. Автоматические рекомендации на следующий приём, а не только учёт факта.
4. Связка учёта питания и покупки в одном сценарии.
5. Минимум действий для ведения дневника.

## 10. Риски продукта и снижение
- **Низкая точность распознавания** → показывать блюдо перед сохранением, давать править, помечать оценку как приблизительную.
- **Недоверие к КБЖУ** → детализация расчёта, объяснение значений, сбор обратной связи.
- **Низкое удержание** → простой фото-сценарий, ежедневный прогресс, ощущение пользы после каждого приёма.
- **Пользователь не видит ценности корзины** → (выводы из анализа: связать корзину с конкретными дефицитами дня).
