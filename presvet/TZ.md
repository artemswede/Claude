# «Пресвет» — техническое задание

Офлайн-плеер MP3 для старой Android-магнитолы. Музыка разбирается по настроению тумблерами, как пресеты на старом радио.

Версия ТЗ: 1.0 · 2 октября 2026

---

## 1. Условия и ограничения

| Параметр | Значение |
|---|---|
| Устройство | Android-магнитола 2018 года, Android 7 (API 24), 2 ГБ ОЗУ, 16 ГБ памяти |
| Экран | Ландшафт, 1024×600, сенсор неточный. Вёрстка должна работать и на 800×480 |
| Источник музыки | USB-флешка |
| Форматы | MP3 |
| Интернет | Не нужен и не используется |
| Питание | При выключении зажигания магнитола перезагружается |

**Технические принципы**
- Kotlin, minSdk 24, View-система (без Compose, чтобы приложение быстро запускалось на слабом процессоре).
- Плеер Media3/ExoPlayer, `MediaSessionService` в foreground.
- Своя медиатека в SQLite, без MediaStore. Сканирование инкрементальное: проверяются только файлы с изменившимися mtime или размером.
- Без Google Play Services, рекламы, аналитики и сети.
- APK меньше 5 МБ, холодный старт меньше 1 с.
- Скевоморфные эффекты отрисовываются заранее (градиенты, 9-patch, векторы). Никакого живого размытия и тяжёлых теней.

## 2. Главный экран («Сейчас играет»)

Единственный экран, на котором проходит вся поездка.

```
┌───────────────────────────────────────────────────────────────┐
│  ╭─────────╮  ╭────────────── LCD-табло ───────────────────╮   │
│  │ круглая │  │ Кино — Звезда по имени Солнце               │   │
│  │ обложка │  │ ● НРВТС  ● НСТЛГ                            │   │
│  │ в хром- │  │ ▬▬▬▬▬▬▬▬▬▬▬▬○────────────────  2:14 / 3:45     │   │
│  │ ободе   │  ╰─────────────────────────────────────────────╯   │
│  ╰─────────╯                                                  │
│   [ПЕРЕМЕШ ●]    ( ⏮ )     (( ▶ ❚❚ ))     ( ⏭ )    [СПИСОК]    │
│                                                               │
│  ┃ВСЕ┃     ●       ●       ○       ●       ○       ○          │
│  ┃ ▲ ┃     ▲       ▬       ▼       ▬       ▬       ▬          │
│  ┗━━━┛   НРВТС   НСТЛГ    РОК    ДОРОГ    СПКН     ·          │
└───────────────────────────────────────────────────────────────┘
```

### 2.1 Обложка
- Круглая, в хромированном ободе. Выглядит как крупная ручка или диск магнитолы.
- Если в MP3 нет обложки: тиснёный логотип «Пресвет» на металле.
- **Удаление трека:** палец держится на обложке 3 секунды, по ободу замыкается кольцо (янтарное днём, красное ночью).
  - Отпустил раньше — отмена, кольцо откатывается назад.
  - Небольшое смещение пальца (тряска) прогресс не сбрасывает. Палец ушёл с обложки — сброс.
  - Кольцо замкнулось — трек перемещается в папку `.Корзина` на флешке, сразу начинает играть следующий.
  - Появляется плашка **«Удалено: <название> · ВЕРНУТЬ»**. Она висит **10 секунд поверх интерфейса**, даже если трек уже переключился. «ВЕРНУТЬ» возвращает файл на место, теги восстанавливаются.

### 2.2 LCD-табло
- Исполнитель и название (бегущая строка, если не помещаются).
- Теги текущего трека: цветные точки и подписи.
- Прогресс: полоса, текущее время и длительность. Перемотка касанием или перетаскиванием.
- Служебные сообщения на 3–5 секунд, например «+37 новых треков» или «Подборка пуста».

### 2.3 Кнопки управления
| Кнопка | Действие |
|---|---|
| ⏮ | Касание: в начало трека, если прошло больше 3 с; иначе предыдущий трек |
| ▶ / ❚❚ | Воспроизведение / пауза |
| ⏭ | Следующий трек по правилам ротации (раздел 4) |
| **ПЕРЕМЕШ** | Кнопка-тумблер с лампой. Лампа горит — случайный порядок, не горит — по папкам и именам файлов |
| **СПИСОК** | Открывает экран «Список» (раздел 5) |

Кнопки руля: стандартные медиа-клавиши (⏮, ⏭, ▶/❚❚) через `MediaSession`. Дополнительных функций нет.

## 3. Тумблеры

### 3.1 Состав
- **ВСЕ** — главный тумблер, крупнее остальных, два положения (вкл / выкл). Тег на него поставить нельзя.
- **6 тумблеров-тегов** — есть всегда, с первого запуска. У каждого три положения рычага и контрольная лампа.

### 3.2 Внешний вид тумблера-тега
- **Рычаг:** ▲ вверх / ▬ середина / ▼ вниз.
- **Контрольная лампа** над рычагом горит, если у **текущего трека** есть этот тег.
- **Подпись** под рычагом: до **5 заглавных букв** гравировкой, как на панели Волги (НРВТС, НСТЛГ, ДОРОГ…).
- **Подложка** окрашена цветом тумблера с прозрачностью **не больше 30%**. Лампа горит тем же цветом в полную силу.
- **Серое состояние:** если ни у одного трека нет этого тега, тумблер серый, лампа и подпись приглушены. Имя и цвет при этом **не забываются** и вернутся, когда тег снова появится у трека.

### 3.3 Ламповые цвета
8 готовых цветов, без свободной палитры:
красный · янтарный · жёлтый · зелёный · бирюзовый · голубой · фиолетовый · белый.

### 3.4 Жесты
| Жест | Результат |
|---|---|
| **Касание** | Середина ↔ ▲ вверх |
| **Свайп вниз** (не меньше половины высоты тумблера) | ▼ исключить |
| **Касание по ▼** | Возврат в середину |
| **Зажатие ~0,7 с** | Поставить или снять тег **текущему треку**, лампа загорается или гаснет |
| Касание по **ВСЕ** | Вкл ↔ выкл |

- Сдвинул палец во время зажатия — тег не ставится. Свайп и зажатие не путаются.
- Каждое переключение сопровождается щелчком тумблера (звук можно отключить в настройках).
- **Первое зажатие пустого тумблера** сразу ставит тег. Тумблер получает следующий свободный ламповый цвет и временное имя «1»…«6». Имя и цвет меняются в Настройках.

### 3.5 Что значат положения
| | ВСЕ включён | ВСЕ выключен |
|---|---|---|
| **▲ вверх** | Этот тег играет **чаще** (свой слот в ротации) | Играет **только** этот тег (вместе с другими поднятыми) |
| **▬ середина** | Тумблер не вмешивается | Тумблер не вмешивается (его треки не выбираются, если у них нет другого поднятого тега) |
| **▼ вниз** | Треки с тегом **никогда** не играют | Треки с тегом **никогда** не играют |

- **Исключение сильнее всего.** Если хотя бы один тег трека опущен, трек не играет.
- **ВСЕ выключен и ни один тумблер не поднят** — играть нечего: ВСЕ сам щёлкает обратно во включённое положение, лампы мигают.
- Если ВСЕ выключен, треки без тегов не играют.

## 4. Ротация (что играет следующим)

**Одно правило: поднятые тумблеры играют по кругу, и ВСЕ тоже считается тумблером.**

| Поднято | Порядок |
|---|---|
| ВСЕ | любой, любой, любой… |
| ВСЕ + РОК | рок, любой, рок, любой… |
| ВСЕ + РОК + НСТЛГ | рок, ностальгия, любой, рок… |
| РОК (ВСЕ выкл) | только рок |
| РОК + ДОРОГ (ВСЕ выкл) | рок, дорога, рок, дорога… |

**Детали**
- **Слот «ВСЕ»** берёт треки, которые **не относятся к поднятым тегам** (включая треки без тегов). Так приоритет не размывается.
- **Трек с несколькими тегами** может выпасть в слоте любого своего поднятого тега. После проигрывания он считается сыгранным во **всех своих подборках** и не повторяется в соседнем слоте.
- **Без повторов:** трек не повторится, пока не проиграна вся его подборка. После этого подборка перемешивается заново, но последние 20 сыгранных треков не попадают в её начало.
- **Пустая подборка** в ротации пропускается, её лампа коротко мигает.
- **ПЕРЕМЕШ выключен:** внутри каждой подборки порядок по папкам и именам файлов, чередование слотов сохраняется.
- **Переключение тумблеров** не прерывает текущий трек: следующий уже выбирается по новым правилам.
- **Трек, включённый из Списка в обход тумблеров,** запускает режим «папка»: дальше играет **следующий трек этой папки**, пока пользователь не нажмёт ⏭ или не переключит любой тумблер. Тогда воспроизведение возвращается к ротации.

## 5. Экран «Список»

### 5.1 Содержимое
- Открывается **папка, в которой лежит играющий трек**, прокрученная к этому треку. Он подсвечен.
- Треки, **не подходящие под тумблеры**, приглушены, но **запускаются касанием** (режим «папка», раздел 4).
- У каждой строки цветные точки-лампы её тегов.
- Кнопка **«↑ Наверх»** — переход в родительскую папку. Так можно ходить по всей флешке.
- Строки крупные (не меньше 72 dp), справа толстый ползунок прокрутки.

### 5.2 Поиск
- Кнопка **клавиатуры** в шапке открывает свою крупную клавиатуру: русская / английская раскладки и цифры.
- Результаты по **всей флешке** обновляются во время ввода.
- Ищется по имени файла, исполнителю и названию из ID3.
- Регистр и «ё/е» не различаются. Транслит: «kino» находит «Кино».

### 5.3 Меню
Кнопка меню (≡) в шапке Списка:
- **Настройки** (раздел 7)
- **Корзина** — удалённые треки: вернуть или удалить навсегда.

## 6. Хранение данных

### 6.1 Теги
- Основная база — SQLite в приложении.
- При каждом изменении копия пишется **на флешку** в `/Пресвет/presvet.json`: тумблеры (имя, цвет, позиция) и теги треков.
- Запись атомарная: сначала временный файл, потом переименование. Выключение зажигания посреди записи ничего не ломает.
- При подключении флешки с `presvet.json`, но без базы (новая магнитола, переустановка) теги восстанавливаются из файла.
- **Как узнаётся трек:** главный ключ — относительный путь от корня флешки. Если файл переименован или перенесён — поиск по размеру, длительности и ID3 «исполнитель + название».
- Сами MP3-файлы **не изменяются**: ID3 не трогаем.

### 6.2 Доступ к флешке на запись
- Android 7 не даёт обычному приложению писать на USB без отдельного разрешения. При первом запуске показывается системное окно выбора папки (Storage Access Framework): пользователь выбирает корень флешки → «Разрешить». Разрешение сохраняется.
- **Это первое, что проверяется на реальной магнитоле**, ещё до основной разработки.
- Если разрешение не работает на прошивке: удаление заменяется на «Скрыть» внутри приложения со списком «на удаление», а `presvet.json` не пишется (теги живут только в базе).

### 6.3 Корзина
- Удалённые треки лежат в `/.Корзина/` на флешке с сохранением структуры папок.
- Очистка вручную в меню «Корзина». Автоочистка через 30 дней (отключается в настройках).

### 6.4 Новые треки
- После подключения флешки или перезагрузки идёт фоновое сканирование. Воспроизведение не ждёт его окончания.
- Новые треки попадают в слот «ВСЕ» без тегов.
- Если появились новые, на LCD-табло на 5 секунд показывается «+N новых треков».

## 7. Настройки

Открываются из меню Списка.

| Раздел | Что настраивается |
|---|---|
| **Тумблеры** | Для каждого из 6: имя (до 5 букв, своя крупная клавиатура, автоматически заглавные) и ламповый цвет из 8 |
| **Ночной режим** | Авто по времени (по умолчанию: день 06:00–18:00, ночь 18:00–06:00, время можно менять) / всегда день / всегда ночь |
| **Звук щелчков** | Вкл / выкл |
| **Корзина** | Автоочистка через 30 дней: вкл / выкл |
| **Флешка** | Повторно выдать доступ на запись, пересканировать |

## 8. Поведение системы

### 8.1 Запуск после зажигания
- Автостарт по `BOOT_COMPLETED`.
- Ожидание монтирования флешки до 30 секунд с повторными попытками.
- **Автовоспроизведение** того же трека, с тем же положением тумблеров и ПЕРЕМЕШ, в той же ротации. Позиция внутри трека — с начала или с сохранённого места (точная секунда не критична).
- Состояние сохраняется при каждой смене трека или тумблера.

### 8.2 Навигатор
- Подсказка навигатора (кратковременная потеря аудиофокуса) — музыка **приглушается** до ~30% и возвращается после подсказки.
- Полная потеря фокуса (другой плеер) — пауза.

### 8.3 Устойчивость
- Битые файлы пропускаются, приложение не падает.
- Foreground service, чтобы система не убила процесс.
- Метаданные для лаунчеров: `MediaSession` и broadcast `com.android.music.metachanged`.

## 9. Визуальный стиль

- **Скевоморфизм Apple 2008–2012 + минимализм + приборная панель советской Волги.** Мало элементов, но каждый сделан как настоящий физический предмет.
- **День:** шлифованный алюминий, LCD-табло голубовато-серое с внутренней тенью, глянцевые выпуклые кнопки.
- **Ночь:** тёмный графит, **янтарная подсветка** подписей и табло, как на приборке 2000-х. Ничего не слепит.
- Подписи — белая гравировка заглавными буквами, шрифт в духе DIN или советских шильдиков.
- Анимации минимальные: щелчок рычага, загорание лампы, кольцо удаления.
- Все касаемые элементы не меньше 64 dp.

---

## 10. Не входит в v1

- Выравнивание громкости между треками (ReplayGain). Вернуться к вопросу после первых поездок.
- Эквалайзер (у магнитолы свой DSP).
- Дополнительные функции кнопок руля.
- Форматы кроме MP3, Bluetooth, стриминг, сеть.
- Режим «И» между тегами.

---

## 11. Порядок разработки

1. **Проверка на магнитоле:** доступ на запись к флешке (SAF), автостарт после зажигания, кнопки руля.
2. Сканер и медиатека, воспроизведение, сохранение и восстановление состояния.
3. Тумблеры, ротация, теги, `presvet.json`.
4. Главный экран в финальном стиле, день и ночь.
5. Список, поиск, меню, Настройки.
6. Удаление, Корзина, «Вернуть».
7. Обкатка в машине.
