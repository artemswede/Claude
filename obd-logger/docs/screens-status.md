# «Бортач»: перенос экранов из Claude Design

Источник — `bortach-ui.zip` (52 экрана). ✅ перенесено · 🟡 частично · ⬜ не начато.

Каждая сборка в CI рисует все экраны только на реальных записанных поездках в трёх размерах — 1280×800, 1024×600, телефон — и выкладывает картинки в релиз `bortach-screens` (тест `app/src/test/.../ScreensTest.kt`). Так вёрстка и шрифты проверяются без планшета. Рядом лежит `ux-report.txt` — автоматический UX-аудит каждого экрана: цели нажатия меньше 44 dp, обрезанный текст, шрифт меньше 12 sp, контраст ниже 4.5:1, элементы за краем экрана.
