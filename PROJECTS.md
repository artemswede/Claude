# Проекты из Claude Code

Источники: ветки репозитория `artemswede/Claude`, репозитории `artemswede/*`, история облачных сессий Claude Code (май–октябрь 2026).
Постоянной памяти (memory-файлов) в Claude Code нет, поэтому список собран по коду и сессиям.

## Новое: продукты и инструменты

1. **WMS-дашборд ЗТЗ**: техника на карте завода в реальном времени (GPS KGK/PackAPI, дороги по плотности GPS, A*-анимация, тепловая карта, точки стоянок). Задеплоен на Cloudflare Workers (`wms-dashboard.artemswede.workers.dev`), дизайн доведён до показа клиенту. Есть промпт для воспроизведения с нуля.
2. **ЕДОНДОН (проект 1949)**: Telegram-бот и Mini App по питанию. КБЖУ по фото (vision-модель Workers AI), цели по Mifflin-St Jeor, дневник, чек-ин самочувствия, движок советов, корзина по дефицитам с партнёрским диплинком. Ядро MVP готово и задеплоено. Ранний прототип, вероятно, `foodai`.
3. **Квантовый навигатор (проект 1950)**: B2B-сервис, который оценивает, подходит ли задача для квантовых вычислений. Конкурентный анализ, дека на 12 слайдов, адаптивная анкета, движок 4-цветных вердиктов (проверен на 16/16 кейсах), MVP на Cloudflare Workers, B2B-лендинг. Процесс шёл по замороженной спецификации с QA-аудитом.
4. **Тендерный бот ТБД**: Telegram-бот, который мониторит тендеры на трубы большого диаметра (Seldon.API, Cloudflare Workers, режим симуляции). Можно подать как часть контура ТЗ Эксперт.
5. **Lean-игра «Велосипедная фабрика»** (`leangame`): браузерная игра по бережливому производству + Android APK. Подходит для обучения и для портфолио трансформации.
6. **Лендинг «ЗТЗ Трубошпунт»**: статический лендинг на Cloudflare Workers со scroll-анимацией.
7. **Навык Алисы с Gemini и веб-поиском**: Vercel + Gemini Flash Lite + Serper. Застрял на отладке POST-вебхука.

## Новое: стратегические кейсы и аналитика

8. **THE GRAND TOUR**: люкс-конструкторы классических авто 1920–30-х в брендированных контейнерах. Стратегический анализ и финмодель, отчёт «Хобби богатых 2020–2030», bear case (провалы, иски, критика) с CSV-датасетами, инвестиционный меморандум в стиле газеты 1920-х. Самый «витринный» аналитический кейс.
9. **18+ AI-компаньон для MAX**: конкурентный анализ, риски, разбор пивота. Вывод: валидировать за 3 дня интервью.
