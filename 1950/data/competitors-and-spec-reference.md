- Статус: косвенный аналог.

- Статус: альтернативный способ + ориентир по формату.

## Блок 3 · Конкурентные преимущества

### Сценарий №1 — «Чем мы выделяемся»

**Вендор-агностичность**
- Наблюдение: вендоры (Braket), частично d-fine, замыкают на свою реализацию.
- Ценность: объективный подбор железа/софта/партнёра под задачу.

**Низкий порог входа**
- Наблюдение: консалтинг = долгие дорогие воркшопы; аналоги требуют знания физики.
- Ценность: бизнес-язык без терминов → быстрый отсев, time-to-market.

**Честность как позиционирование**
- Наблюдение: рынок перегрет хайпом; «успехи» в основном PoC, а не продакшн.
- Ценность: вердикт включает «классика» и «рано» → доверие серьёзных покупателей.

**Встроенный классический бейзлайн**
- Наблюдение: без вопроса «где ломается классика» вердикт не обоснован.
- Ценность: честный, защищаемый светофор, а не маркетинг.

**Учёт зрелости архетипа**
- Наблюдение: рынок меряет «квант да/нет»; но симуляция ≠ оптимизация по реализму.
- Ценность: приоритет реально достижимым задачам уже сейчас.

### Сценарий №2 — «Чем Q-Scope выделяется на рынке»

**Независимость от вендоров**
- Наблюдение: конкуренты привязывают оценку к своему железу/платформе.
- Ценность: непредвзятая рекомендация и охват любых задач и поставщиков → доверие.

**Сниженный порог входа (self-service)**
- Наблюдение: квантовые офферы — sales-gated консалтинг; спрос на self-service анкеты доказан (MS/AWS).
- Ценность: быстрый сигнал без обязательств → масштабируемая воронка лидов.

**Язык бизнеса, без квантовой физики**
- Наблюдение: конкуренты требуют от клиента тех-грамотности (IBM/D-Wave).
- Ценность: доступно бизнес-заказчику; структурирует задачу в бизнес-терминах.

**Честное управление ожиданиями**
- Наблюдение: рынок перегрет хайпом, гарантий эффекта нет.
- Ценность: ранний отсев нецелевых кейсов → качественные лиды и стандартизированные данные.

**Мост к экспертам + структурированный бриф**
- Наблюдение: assessment-инструменты заканчиваются отчётом и не ведут к next step.
- Ценность: готовый бриф экономит время экспертов; чёткий next step и точка монетизации.

## Блок 4 · Состав MVP (первая версия)

### Сценарий №1 — «Что собрать в первую очередь» (V1)

1. **Квантовый канвас** — бизнес-анкета без физ-терминов: задача · боль · масштаб · цель.
2. **Модуль «Классический бейзлайн»** — где упирается текущее решение — обоснование вердикта. *(добавлено)*
3. **Скоринг-светофор с архетипом** — Симуляция / Сэмплинг / Оптимизация / QML + «Классика» / «Рано».
4. **Библиотека референсов** — с 5-уровневой маркировкой «успеха» — анти-хайп и доверие.
5. **Одностраничный бриф + маршрутизация** — стандартизация ответов → передача пулу экспертов.
6. **Анти-хайп онбординг** — короткий блок, развенчивающий мифы; управление ожиданиями.
7. **Лид-капчер + сбор данных** — структурированные входы + согласие эксперта с вердиктом (петля).

**Фокус v1:** «структурировать задачу и передать экспертам». Без реального запуска кванта и интеграций.

### Сценарий №2 — «Состав первой версии продукта (MVP)»

1. **Интерактивная анкета на языке бизнеса** — реализует «язык бизнеса» и «низкий порог»: задача, боль, масштаб, цель.
2. **Система скоринга (rule-based классификатор)** — архетип + вердикт «перспективно / неочевидно / вряд ли»; ядро приоритизации без запуска кванта.
3. **Прозрачный скоринг + дисклеймер** — поддерживает «честные ожидания»: понятная логика и «без гарантии эффекта».
4. **Бриф-артефакт на выходе** — реализует «мост к экспертам»: одностраничный структурированный бриф задачи.
5. **Флоу хэндоффа к экспертам** — запись на консультацию / очередь экспертов + лид-капчер.
6. **База референсов и типовых вопросов** — подсказки и примеры use-case по отраслям (ориентир — D-Wave / MS / AWS).
7. **Сбор данных + жёсткий скоуп** — обезличенные анкеты → база знаний; без интеграций и реального кванта в v1.

**Фокус MVP:** структурировать задачу и передать её экспертам — без избыточного усложнения на старте.

### A1 · Решение собственника — скоркарта «идти ли в квант?» (профиль металлургии)

| Критерий | Вес | Что меряем |
|---|---|---|
| **ГЕЙТ · Доступ к железу** (РФ / экспортный контроль / Росатом) | PASS/FAIL | Нет доступа → STOP, дальше не считаем |
| Зрелость своей классической базы (DFT / CALPHAD / ICME) | 20% | Есть ли вычислительное материаловедение — субстрат для кванта |
| Связь с P&L | 20% | Брак/выход годного, кокс/энергия, новые марки, коррозия/ресурс, импортозамещение |
| Талант / absorptive capacity | 15% | Люди, понимающие и квант, и металлургию |
| Зрелость архетипа | 12% | Симуляция материалов = green; оптимизация = red |
| Альтернативная стоимость | 10% | Квант против ваших же AI/CV-инициатив за тот же бюджет |
| Консолационный приз (floor) | 8% | Окупится ли при провале: команда, пайплайны, IP, связь с Росатомом |
| Эксклюзивность IP + безопасность данных | 6% | Проприетарные данные по сплавам и процессам |
| Горизонт / риск-аппетит собственника | 5% | Терпит ли стратегия ставку с отдачей ~2030+ |
| Конкурентный угол | 4% | Движутся ли Северсталь / EVRAZ / глобальные игроки |

**Логика вердикта:** гейт пройден → взвешенный балл (1–5 × вес): ≥70% Зелёный (пилот сейчас) · 45–69% Жёлтый (строить классику + наблюдать) · <45% Красный (рано / классика).

### A2 · Сторона провайдера — приоритизация воронки под коммерческую выгоду

**Ожидаемая коммерческая ценность ≈**
P(показуемого выигрыша) × (размер пилота + референс + reusable IP) ÷ (цена и время до 1-го результата)

Факторы:
- **Ценность на кону** — $ в задаче клиента → размер сделки.
- **Зазор от классики** — где классика реально упирается.
- **Зрелость архетипа** — симуляция > сэмплинг > оптимизация > QML.
- **Время/цена до результата** — короткий цикл = высокая конверсия.
- **Готовность задачи и данных** — кодируется ли, есть ли данные.
- **Бюджет / со-финансирование** — реальные деньги (Росатом), а не интерес.
- **Референс и reusable IP** — мультипликатор на следующих клиентов.
- **Стратегический фит** — партнёрский рычаг, доступ к рынку.

**Контринтуитивное правило (лестница доверия):** самая «ценная» задача (огромная логистическая оптимизация) — часто худший первый проект: выигрыш недоказуем. Заходить через быстрый дешёвый near-term-выигрыш (симуляция / quantum-inspired) → референс-кейс → крупные квантовые ставки.

### A3 · Калибровка вердикта — зрелость архетипов и уровни «успеха»

**Зрелость архетипа (near-term):**
- **Симуляция (химия / материалы)** — сильнейший near-term кейс, «родная» задача.
- **Сэмплинг (Монте-Карло / финансы)** — квадратичные ускорения, нужен FT-хардвер.
- **Оптимизация (логистика)** — самый хайп, наименее доказан vs классика.
- **QML** — самый спекулятивный; узкое место — загрузка данных.

**5 уровней «успеха» (маркировка кейсов):**
1. **Продакшн-преимущество** — обыгрывает классику в проде — почти не существует.
2. **Документированный PoC** — обыграл бейзлайн на узкой задаче — редкие, ценные.
3. **Исследовательская коллаборация** — вендор + корпорация, без доказанного выигрыша.
4. **Quantum-inspired** — классика, вдохновлённая квантом — работает уже сейчас.
5. **Маркетинг** — пресс-релиз без бейзлайна — в библиотеку не берём.

**Честно:** на начало 2026 практического квантового преимущества в проде почти нет — реальные «успехи» в основном уровни 2–4.

### A4 · Доказательная база (проверено) — карта реальных кейсов по отраслям

**Химия / материалы — самый сильный угол:**
- BASF, Covestro, Johnson Matthey, Mitsubishi Chemical — симуляция материалов и катализа.
- IonQ + Ansys: медустройство +12% точности vs классический HPC.
- IonQ + автопроизводитель (Global-1000): атомные силы точнее классики.

**Фарма:**
- AstraZeneca: ~20× ускорение на реакции Suzuki–Miyaura (IonQ + AWS + NVIDIA).
- Программы Boehringer Ingelheim, Sanofi, Merck — позиционирование и таланты.

**Криптография — это пост-квант, не «преимущество»:**
- Оценка взлома RSA-2048 упала с ~20 млн (2019) до <1 млн физ. кубитов (2025).
- Реальная near-term история отрасли — защита (PQC), а не подбор задач.

*Источники: The Quantum Insider, IonQ, C&EN, SpinQ, arXiv (2025–2026). Практического квантового преимущества в проде пока нет.*

### A5 · РФ-контекст — гейтовые критерии для собственника в РФ

- **Доступ к железу — проверять ПЕРВЫМ.** Топ-облака (IBM, IonQ, Quantinuum через AWS/Azure) под вопросом из-за экспортного контроля. Нет доступа → дальше можно не считать.
- **Росатом — не «апсайд», а канал доступа.** Для метхолдинга в РФ домашний/росатомовский маршрут может быть единственным каналом доступа к железу + со-финансирование.
- **Классика — сначала.** Усилить вычислительное материаловедение (DFT/CALPHAD/ICME): даёт ROI уже сейчас и является субстратом для кванта.
- **Альтернативная стоимость.** Квант конкурирует с вашим же AI/CV-портфелем за тот же бюджет — но с горизонтом на 5+ лет дальше и без доказанного ROI.

**Вердикт собственника:** вопрос не «квант да/нет», а «квант — вместо чего из доказуемого».

### Процесс — как конкуренты выстраивают работу с клиентом

Общая воронка:
1. **Discovery** — поиск задачи.
2. **Assessment** — оценка применимости.
3. **PoC / Pilot** — прототип на данных.
4. **Production** — внедрение и сопровождение.

*Общая схема у квантовых игроков — консалтинго-ведомая, sales-gated, требует тех-грамотности клиента.*

- **D-Wave Launch** — проф. услуги: эксперты «переводят» задачу в QUBO; доставка через облако Leap.
- **IBM Quantum** — членство (Network) + working groups + обучение Quantum Business Foundations.
- **Multiverse / QC Ware** — продукт (Singularity / Forge) + консалтинг; discovery → PoC → deployment.
- **MS / AWS (эталон)** — self-service анкета по pillars без консультанта; хэндофф к партнёрам.

**Наш сдвиг (Q-Scope):** self-service анкета на входе вместо sales-gated discovery → быстро и дёшево квалифицируем задачу, дальше — бриф к экспертам. Vendor-нейтрально.

### Движок приоритизации инициатив

**Шаг 1. Gate-фильтры (любое «нет» → не для кванта):**
1. Классика провисает (экспоненциально / NP-трудно).
2. Формализуемо как QUBO / Hamiltonian (цель + ограничения).
3. Нет I/O-bottleneck (вход мал относительно решений).

**Шаг 2. Взвешенный скоринг (0–5):**
- 25% — Бизнес-ценность / ROI.
- 25% — Классическая твёрдость + speedup.
- 15% — Архетип-fit (симуляция/оптимизация ≫ QML).
- 15% — Реализуемость (NISQ сейчас vs FT).
- 10% — Готовность данных / инфры / команды.
- 10% — Допустимость приближённого решения.

**Шаг 3. Матрица 2×2 → приоритет:**
- Оси: ↑ Квантовый потенциал; → Бизнес-ценность / реализуемость.
- Квадранты: **Watchlist** · **PoC сейчас** · **Отбросить** · **Классический / гибридный солвер**.

### MVP — бриф задачи и подготовка клиента

**Структура брифа (12 секций):**
- Владелец задачи и роли (кто решает, кто платит).
- Бизнес-задача в одном предложении: «как есть» → «как надо».
- Текущее решение и боль (время / стоимость / качество).
- Тип задачи и цель (что значит «лучше»).
- Переменные решения (что можно менять).
- Ограничения (жёсткие / мягкие).
- Масштаб (число объектов; рост со временем).
- Данные (объём, формат, доступность, чувствительность).
- Метрика успеха и базовая линия.
- Частота и режим (разово / real-time).
- Экономика (стоимость, цена ошибки, эффект).
- Готовность и ограничения (ИТ, бюджет, комплаенс).

**Кого пригласить и что подготовить:**
- Бизнес-заказчик — боль, метрика, эффект.
- Профильные операции — процесс, ограничения, объёмы.
- Владелец данных — какие данные, объём, доступ.
- ИТ / инфраструктура — где данные, интеграции, безопасность.
- Финансы — стоимость решения, цена ошибки, ROI.
- Комплаенс (опц.) — ограничения на данные.

*Сервис выдаёт этот чек-лист, чтобы клиент пришёл подготовленным и собрал нужные службы.*

### MVP — адаптивная анкета без брифа (чат-бот)

**Уровни анкеты:**
- Уровень 0: отрасль и роль.
- Уровень 1: тип задачи → архетип: оптимизация / симуляция / сэмплинг / ML.
- Уровень 2: признаки комбинаторного взрыва и боль классики (gate G1).
- Уровень 3: формализуемость: цель + переменные + ограничения (gate G2).
- Уровень 4: данные и I/O-bottleneck (gate G3).
- Уровень 5: масштаб, частота, экономика → бизнес-ценность.
- Уровень 6: готовность: данные / ИТ / команда / комплаенс.

**Принцип (адаптивная анкета):**
- От общего к частному, ветвление по ответам.
- Закрытые ответы → детерминированный скоринг.
- «Не знаю» не блокирует; индикатор «похоже на…».
- 8–15 вопросов до результата.

**Выход: сценарий + эффект:**
- Вердикт: PoC · Watchlist · Классики достаточно.
- Сценарий: «ваша задача — {подтип}, формализуется как QUBO, подход — гибридный солвер, как кейс {референс}».
- Оценка эффекта (вилка по аналогии) — не гарантия.
- Кнопка «передать экспертам» → авто-бриф (PDF).

### Карта кейсов — 16 кейсов: квантовый потенциал × бизнес-ценность

- Оси: ↑ Квантовый потенциал; → Бизнес-ценность / реализуемость.
- Квадранты: **Watchlist** · **PoC сейчас** · **Отбросить** · **Классический солвер**.
- Точки кейсов по направлениям: **Логистика (L1–L4)**, **Производство (P1–P4)**, **Химия (C1–C4)**, **Финансы (F1–F4)**.

**Как читать:**
- Точка — 1 кейс (ID из CSV).
- Положение = баллы движка (X×Y).
- Точки в ячейке разнесены (jitter).
- Квадрант = вердикт приоритизации.
