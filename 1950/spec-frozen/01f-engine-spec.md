## 2. Обработка «не знаю» (фикс A5)
- Любой ответ может быть «не знаю» → **нейтральный балл = 2.5** для своего фактора; одиночное «не знаю»
  **не переключает gate** само по себе.
- Числовое «не знаю» (A2/T3) → нейтральный bucket (см. ниже).
- `confidence = заполнено / всего`. Если `confidence < 0.6` — к вердикту приписка
  **«предварительно, требуются уточнения»**, в брифе пробелы помечены.

## 3. `scale_score`
- **A2 (число):** <10→0 · 10–49→1 · 50–499→2 · 500–4 999→3 · 5 000–49 999→4 · ≥50 000→5 · не знаю→2.5.
- **B3 (категория):** маленькая→1 · средняя→3 · большая→5 · не знаю→2.5.

## 4. Gate-фильтры по ветке (фикс A6)
**Ветка A (оптимизация):**
- **G1** = (A4 = «не хватает»/«частично») И (A5 = «резко» ИЛИ `scale_score ≥ 2`).
- **G2** = A3 (есть жёсткие ограничения) И A6 (чёткая цель) → PASS; одно из двух → «Частично».
- **G3** = T1 ≠ «очень большие массивы» → PASS; иначе FAIL.

**Ветка B (симуляция):**
- **G1** = B2 = «обычных методов не хватает по точности/масштабу».
- **G2** = B4 (понятная цель расчёта) → PASS.
- **G3** = PASS по умолчанию (I/O для симуляции не лимитирует).

> «Частично»/«Borderline» в вердикте трактуются как **мягкий PASS** (жёсткий — только явный FAIL). Это
> подтверждено на CSV (кейсы L2/P2 проходят как Watchlist, а не отсекаются).

## 5. Критерии 0–5 и оси (фикс A4 — валюта и пороги стоимости)
Валюта зафиксирована — **₽**.
- **`c_value`** (T3): не знаю→2 · <1 млн→1 · 1–10 млн→2 · 10–100 млн→3 · 100 млн–1 млрд→4 · >1 млрд→5;
  **+1**, если T2 ∈ {ежедневно, постоянно}; максимум 5. *(не обнуляем важную задачу при «не знаю».)*
- **`c_hardness`** = среднее( pain, `scale_score`, growth ), где
  pain = A4{Нет→5 / Частично→3 / Да→0} **или** B2{не хватает→5 / хватает→1};
  growth = A5{резко→5 / понемногу→2 / нет→0} (для B — нейтрально 2.5).
- **`c_archfit`** = Симуляция 5 · Оптимизация 4 *(Сэмплинг 3 · ML 2 — ветки отключены в MVP)*.
- **`c_feasibility`** = Оптимизация 5 · Симуляция при `scale_score ≤ 3` → 4, иначе 2.
- **`c_readiness`** = T4{Высокая 5 / Средняя 3 / Низкая 1}.
- **`c_approx`** = T5{Да 5 / Зависит 3 / Нет 1}.

**Оси:**
- **Y (квантовый потенциал)** = 0.5·`c_hardness` + 0.3·`c_archfit` + 0.2·`c_approx`.
- **X (бизнес-ценность/реализуемость)** = 0.5·`c_value` + 0.3·`c_feasibility` + 0.2·`c_readiness`.

## 6. Таблица истинности вердикта (фикс A3) — порог high = **≥ 3.0**
```
есть хотя бы один жёсткий FAIL (G1|G2|G3 == FAIL):
    X ≥ 3  → 🔵 «Есть классическое решение» (Классический солвер)
    X < 3  → 🔴 «Квант здесь не нужен»      (Отбросить)
все gate PASS (мягкие «Частично» = PASS):
    Y ≥ 3 И X ≥ 3 → 🟢 «Можно начинать пилот»     (PoC сейчас)
    иначе          → 🟡 «Перспективно — вернёмся позже» (Watchlist)
```
Покрыты все ветки: «слабо/слабо при gates PASS» → 🟡 (не 🔴 — задача хотя бы прошла фильтры). 🔴 достижим
только при жёстком FAIL и низком X. Граница `=3` → high.
