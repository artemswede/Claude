# Шаг 1. Бизнес-требования — Project 1950

> Статус: 🟡 заполнено со слов владельца продукта (17.06.2026). Требует финальной вычитки.
> Кодовое имя проекта: **1950**. Продукт: бриф-бот квалификации квантовых бизнес-задач (механика «Акинатор»).
> К Шагу 2 (архитектура) не переходим без явного запроса владельца.

## 1. Идея и проблема
- **Что это:** веб-бриф-бот в стиле «Акинатор» — через серию вопросов определяет, подойдёт ли бизнес-задача
  клиента для квантовых технологий, и собирает структурированный бриф.
- **Проблема:** клиент хочет внедрить квантовые технологии, но не знает, применимы ли они к его задаче.
- **Для кого:**
  - внешне — бизнес-заказчик / стратег, рассматривающий квант (без знания физики);
  - внутренне — бизнес-аналитики, которым нужен стандартизированный бриф для ранжирования и подготовки
    уточняющего интервью.

## 2. Основной сценарий использования
1. Клиент открывает ссылку → короткий онбординг.
2. Отвечает на серию вопросов (от общего к частному): выбор варианта **или** свободное число.
3. Скрипт детерминированно вычисляет архетип + gate-фильтры + баллы → **вердикт**: может ли задача
   решаться квантом.
4. Клиент видит вердикт + сценарий решения (референс-кейс, оценка эффекта, дисклеймер).
5. Формируется **бриф** → идёт бизнес-аналитикам для ранжирования и уточняющего интервью.

## 3. Бизнес-цель и метрики
- **Цель:** стратегический проект — понять, **куда внедрять квантовые технологии**, чтобы зарабатывать в
  будущем. Продукт **не монетизируется**.
- **Метрики:** не выбраны — см. предложения в `docs/01b-mvp-mechanics-DRAFT.md` (владелец выбирает).

## 4. Объём первой версии (Scope)
- Предложения по составу v1 — в `docs/01b-mvp-mechanics-DRAFT.md` (владелец выбирает).
- Точно НЕ входит: работа с пользовательскими данными, внешние интеграции, реальный запуск кванта.

## 5. Ограничения и контекст
- **Стек:** Cloudflare Workers + TypeScript.
- **Хостинг:** бесплатный; результат — шарящаяся ссылка для демонстрации другим.
- **UI:** белый фон, минимализм, яркие тёмно-/светло-синие акценты, иконки.
- **Срок:** MVP, сегодня–завтра. **Команда:** 1 человек.
- **Данные:** работы с данными нет; сценарии **зашиты заранее из CSV** (`data/scenarios.csv`).
- **Алгоритм:** ответы (выбор варианта или свободное число) → скрипт выдаёт детерминированный результат.
- **Интеграции:** нет. **Регуляторика:** не определена (для MVP не блокирует).
