# Шаг 1b. Механика и сценарии MVP — ЧЕРНОВИК для обсуждения

> 🟠 ЧЕРНОВИК. Обсуждаем и фиксируем вместе. Решения помечены **[РЕШИТЬ]**.
> Это всё ещё Шаг 1 (требования). Архитектура (Шаг 2) — после утверждения механики.

## 1. Пользовательский поток (предлагаемый)
```
[Онбординг 1 экран] → [Анкета: вопросы от общего к частному] → [Движок: gate+скоринг+архетип]
   → [Экран результата: вердикт + сценарий + эффект + дисклеймер] → [Бриф: показать/скачать]
```

## 2. Анкета (механика «Акинатор»)
Берём готовое дерево из `data/competitors-and-spec-reference.md` (уровни 0–6):
- **Ур.0** — отрасль и роль.
- **Ур.1** — тип задачи → архетип: оптимизация / симуляция / сэмплинг / ML.
- **Ур.2** — признаки комбинаторного взрыва и боль классики → **gate G1**.
- **Ур.3** — формализуемость (цель + переменные + ограничения) → **gate G2**.
- **Ур.4** — данные и I/O-bottleneck → **gate G3**.
- **Ур.5** — масштаб, частота, экономика → бизнес-ценность.
- **Ур.6** — готовность (данные/ИТ/команда).
- Ветвление по ответам; «Не знаю» не блокирует; 8–15 вопросов до результата.

## 3. Движок вердикта (детерминированный, без БД)
1. **Gate-фильтры** (любое «нет» → не для кванта): G1 классика провисает · G2 формализуемо (QUBO/Hamiltonian)
   · G3 нет I/O-bottleneck.
2. **Классификация архетипа** по ответам Ур.1 (+ уточнения).
3. **Взвешенный скоринг 0–5** (веса): бизнес-ценность 25% · классическая твёрдость+speedup 25% ·
   архетип-fit 15% · реализуемость 15% · готовность 10% · допустимость приближённого 10%.
4. **Две оси → квадрант:** X = бизнес-ценность/реализуемость, Y = квантовый потенциал.

## 4. Выход / сценарий (из CSV + библиотеки)
- **Вердикт** [РЕШИТЬ — модель]: 4 квадранта (PoC сейчас / Watchlist / Классический солвер / Отбросить)
  **или** светофор 3 уровня (Перспективно / Неочевидно / Вряд ли).
- **Сценарий решения:** «ваша задача — {подтип} ({архетип}), формализуется как QUBO, подход — {квант/гибрид/
  классика}, как кейс {референс}» (берётся из библиотеки сценариев и `data/scenarios.csv`).
- **Оценка эффекта:** вилка по аналогии с референс-кейсом + **дисклеймер «не гарантия»**.
- **Бриф** для бизнес-аналитиков: 12 секций (см. reference) + архетип + баллы + вердикт.

## 5. [РЕШИТЬ] Открытые решения
- **D1. Модель вердикта:** 4 квадранта (как в CSV) / светофор 3 уровня / 5 уровней.
- **D2. Тип ввода:** только закрытые ответы / закрытые + несколько числовых полей.
- **D3. Доставка брифа в MVP:** показать на экране + скачать (.md/PDF) / + лид-капчер / + хранение.
- **D4. Метрики:** см. ниже.
- **D5. Состав v1:** см. ниже.

## 6. [РЕШИТЬ — D4] Метрики (предложения, выбрать нужные)
- Completion rate — доля дошедших до вердикта.
- Распределение вердиктов и архетипов/отраслей.
- Кол-во сгенерированных брифов (квалифицированные инициативы для аналитиков).
- Среднее число вопросов до результата.
- (пост-MVP) Согласие аналитика с вердиктом — петля качества.

## 7. [РЕШИТЬ — D5] Состав v1 (обязательное ядро + опции)
**Ядро (предлагается зафиксировать):**
1. Анкета-Акинатор (дерево вопросов, закрытые + числовые).
2. Движок-вердикт (gate + скоринг + архетип) — без запуска кванта.
3. Экран результата: вердикт + сценарий + эффект + дисклеймер.
4. UI: белый фон, минимализм, синие акценты, иконки; одна шарящаяся ссылка.

**Опции (выбрать):**
- Авто-бриф со скачиванием (.md/PDF).
- Анти-хайп онбординг (1 экран).
- Лид-капчер (имя/почта в конце).
- Мини-аналитика прохождений (счётчики).

**Вне v1:** работа с данными пользователя, интеграции, реальный квант, доставка брифа аналитикам напрямую.
